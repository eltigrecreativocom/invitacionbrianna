INVITARTE - exportación estática: demo

Contenido:
- index.html: página de la invitación.
- assets/: imágenes, MP3, fuentes, estilos y reproductor.
- .nojekyll: evita que GitHub Pages transforme los archivos.

Publicar en GitHub Pages:
1. Descomprime todo el ZIP sin cambiar la estructura.
2. Sube index.html, assets y .nojekyll a la raíz del repositorio.
3. En GitHub abre Settings > Pages y publica la rama correspondiente.

Las imágenes y MP3 subidos a INVITARTE están incluidos. Los enlaces externos y YouTube requieren internet.
No abras únicamente index.html dentro del ZIP: primero debes descomprimirlo.
